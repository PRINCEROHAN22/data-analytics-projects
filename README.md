# Sales Dashboard - Data Analytics Project

## About
This project analyzes sales data from a Superstore dataset using Python, Pandas, and Matplotlib. It explores sales patterns across categories, regions, states, and customer segments.

## Dataset
- **Source:** Sample Superstore Dataset (Kaggle)
- **Records:** 9,994 sales transactions
- **Columns:** Order details, Customer Segment, Region, State, Category, Sales, Profit, etc.

## Analysis Performed
- Total Sales by Category
- Total Profit by Region  
- Top 10 States by Sales
- Sales by Customer Segment (Pie Chart)
- Sales vs Profit scatter plot
